# m8y Connect – Downloads

**English:** Download page for m8y Connect – program files only (no source code).
Get the latest version under [Releases](https://github.com/manualto/m8y-sync-share-releases/releases/latest):

- `m8y-Connect-Setup-<version>-b<build>.exe` – Windows installer (recommended)
- `m8y-Connect-Portable-<version>-b<build>.exe` – Windows, without installation
- `m8y-sync-share-<version>.apk` – Android app

Installed apps update themselves automatically from this page. Every update is signed; unsigned files are rejected.
